# E4 Lovasz 实验结果与原 E4 对比

更新日期：2026-11-17。正式训练由用户手动完成；本轮独立验证和结果整理未继续训练。

## 结论

本次 `BCE + Dice + 1.0 × Lovasz hinge` 未提高固定91张验证集的耕地 IoU。
原 E4 为 79.755413%，新实验为 79.708067%，
低 0.047347 个百分点，数值非常接近。
二类 mIoU 也从 85.051103% 变为 84.919297%。
暂继续使用原 E4，保留新实验供后续研究；没有替换 E4_UPerNet.zip 或任何网站 tar。
这里只说明本次权重、系数及训练设置的结果，不能据单次实验断言 Lovasz 普遍无效，也不能预测官网分数。

## 训练与选权重

- 完成 45 轮；最佳第 30 轮，随后连续15轮未提升而早停。
- 新权重：`runs/e4_upernet_r50_lovasz/best.pt`，SHA256：`f66b887ee8b0a5c79b97cb9ba2d458ac192a7a3ddef9c506816345d133c2b839`。
- 原 E4 最佳第 69 轮；原 best.pt 的 SHA256 已核验未改变：`e39a2b459da13c3d45ae4f99b9300a5d37f19287144ff6b75239db4c6aba4369`。
- 原 train719/val91，512×512 RGB、0背景/1耕地，固定预处理，seed42。按阈值0.5累计全部验证像素混淆计数选择 best.pt。
- 实际保存的模型配置、骨干预训练来源、划分指纹和预处理均与原 E4 相同；训练配置只差 lovasz_weight 和独立 run_dir。
- 从原 ImageNet ResNet-50 骨干初始化，未加载旧 E4 best.pt 继续微调；主头及0.4倍辅助头均加入同样的 Lovasz 项。
- batch2、累积4、AdamW 1e-4、5轮warmup+cosine、最多100轮、早停15。Lovasz 在实际batch2像素上排序，以float32计算。
- 新训练共 4049 次优化器更新，峰值已分配显存 2681.7 MiB。
- 本轮没有使用内部 test 调参或评估，也没有搜索阈值、融合权重或启动下一轮训练。

## 相同验证协议的成绩

以下来自各自 best.pt 对应的训练期完整验证记录，均为 batch2、阈值0.5。

| 最佳权重的验证指标 | 原 E4 | E4 + Lovasz | 差值（百分点） |
| --- | ---: | ---: | ---: |
| 耕地 IoU | 79.755413% | 79.708067% | -0.047347 |
| 背景 IoU | 90.346793% | 90.130527% | -0.216266 |
| 二类 mIoU | 85.051103% | 84.919297% | -0.131806 |
| F1 | 88.737704% | 88.708390% | -0.029314 |
| Precision | 89.468218% | 88.172987% | -1.295231 |
| Recall | 88.019023% | 89.250336% | +1.231312 |
| Accuracy | 93.006427% | 92.887786% | -0.118641 |

新模型 TP=6,664,460，FP=893,932，FN=802,694，TN=15,494,018。
相比原 E4，漏检减少 91,944 像素，但误检增加 120,246 像素；召回更高、精确率降低，最终 IoU 略低。
第30轮后训练loss从 1.0433 降到 0.8206，而验证loss从 1.0437 增到 1.2854，后续出现泛化变差的迹象。
新增损失项改变了loss绝对尺度，不把新旧loss的绝对数值作直接优劣比较。

报告日期：2026-10-27（北京时间）。实验：b5_server；实际训练设备为本地 NVIDIA GeForce RTX 4060 Laptop GPU 8GB。配置文件名中的 server 不代表此次在远程服务器训练。

本次已完成 512×512 完整训练，因早停结束于第 46 轮；按验证集耕地 IoU 选择的第 31 轮最佳模型，在 90 张内部保留测试图上取得耕地 IoU 78.17%、F1 87.75%、mIoU 83.88%。这是一条可复现的比赛基线，但尚无官方平台成绩，不能据此判断排名或获奖水平。

## 1. 数据、模型与训练设置

| 项目 | 实际设置 |
| --- | --- |
| 数据来源 | OGE 大赛提供的 900 对 RGB TIFF 与耕地标签；不是官方隐藏测试集 |
| 固定划分 | 训练 719 张 / 验证 91 张 / 内部测试 90 张；seed=42 |
| 输入与标签 | 512×512，RGB uint16；标签 0=背景、1=耕地；背景参与评估 |
| 模型 | SegFormer-B5；MiT-B5 预训练编码器，完整微调；单一模型 |
| 预处理 | 只使用训练集拟合的固定显示/缩放范围 [0,1634]，然后 ImageNet 均值方差归一化 |
| 损失 | BCEWithLogits + 逐图 soft Dice loss，等权；boundary_weight=0 |
| 优化器 | AdamW；初始目标学习率 6e-5；weight decay=0.01 |
| 学习率计划 | 5 轮预热 + cosine；计划 100 轮，早停 patience=15 |
| 批量与精度 | batch=2，梯度累积4次；通常有效批量8，末尾不足部分按样本加权；CUDA AMP |
| 训练增强 | 同步水平/垂直翻转与90度旋转，图像亮度/对比度/饱和度扰动 |
| 记录的训练显存峰值 | 5221.34 MiB（PyTorch 分配峰值，不等同显卡总占用） |
| 实际优化器更新 | 4,140 次；46轮每轮90次 |
| 权重选择 | 仅由验证集耕地 IoU 决定；本次测试未搜索阈值、未重新训练 |

原始官方数据仍保留。PNG 原图为方便观察，由 uint16 影像按同一固定范围映射为 8 位显示图，并非原始 TIFF 的无损数值副本；真值及预测面板没有缩放或平滑。

## 2. 训练过程与早停原因

| 阶段 | 训练 loss | 验证 loss | 验证耕地 IoU |
| --- | --- | --- | --- |
| 第1轮 | 1.2405 | 0.8496 | 61.31% |
| 第11轮（验证loss最低） | 0.3246 | 0.3793 | 78.93% |
| 第31轮（最佳IoU，采用） | 0.1350 | 0.4236 | 81.29% |
| 第46轮（早停） | 0.0966 | 0.5112 | 80.78% |

第32至46轮连续15轮未超过第31轮的验证 IoU，因此触发正常早停。后期训练损失持续下降，但验证损失总体上升且 IoU 未再突破，显示过拟合迹象。验证 loss 最低的轮次并不等于 IoU 最高的轮次，这是损失函数与阈值化评估指标不同所致。

best.pt 用于本次测试；last.pt 保留断点续训状态。本次未修改原训练配置、原划分、原模型权重，也未为提高分数改变标签或阈值。

## 3. 测试协议与总体结果

使用现有部署推理路径，完整评估 splits/test.csv 中的90张图，partial=false。模型来自 runs/b5_server/best.pt 的第31轮；输入原尺寸512×512，tile=512，阈值固定0.5，无TTA、无后处理、无模型集成。重叠参数默认0.25，但这些图片恰好各占一个窗口，没有多窗口融合。推理使用CUDA自动混合精度。

验证指标取自训练日志中第31轮的91张验证图；测试指标由本次独立运行生成。全局指标先累加所有像素的 TP/FP/FN/TN，再计算比值；不是先算每张图再平均。

| 指标 | 最佳验证集（91张） | 保留测试集（90张） |
| --- | --- | --- |
| 耕地 IoU | 81.29% | 78.17% |
| 背景 IoU | 90.94% | 89.59% |
| mIoU（两类平均） | 86.11% | 83.88% |
| F1 / 二值 Dice | 89.68% | 87.75% |
| Precision（查准率） | 89.14% | 86.57% |
| Recall（查全率） | 90.22% | 88.96% |
| 像素准确率 | 93.50% | 92.42% |

测试耕地 IoU 比最佳验证集低 3.12 个百分点。测试 Precision=86.57%，表示被预测为耕地的像素中约有 13.43% 是误检；Recall=88.96%，表示真实耕地约有 11.04% 被漏掉。这些是像素统计，不是田块个数统计。

| 真实类别 / 预测类别 | 预测为耕地 | 预测为背景 |
| --- | --- | --- |
| 真实耕地 | TP = 6,406,767 | FN = 795,188 |
| 真实背景 | FP = 994,317 | TN = 15,396,688 |

共评估 23,592,960 个像素；误检 994,317 个，漏检 795,188 个。像素准确率包含较多背景像素，不能用它代替耕地 IoU。

## 5. 可靠性检查与局限

已独立核验90对测试影像及标签的数组SHA256与原划分清单完全一致；全部90个预测TIFF的尺寸、空间参考、uint8类型、单波段和0/1取值合法；PNG的原图显示、真值、预测、误差四个面板与源数据逐像素一致；独立复算的混淆计数与指标文件完全一致。所有测试图均512×512；没有发现RGB三个通道同时为0但标注为耕地的像素。数据哈希吻合只证明没有文件错配/改动，不证明语义标注一定正确。

代码验证：11项测试全部通过，包括新增PNG像素与误差颜色验证、既有分割推理与断点恢复测试。首次测试因系统临时目录权限失败，改用项目内新临时目录后通过；有12条Rasterio/Affine弃用提示，不影响本次结果。

[全量产物核验记录](../outputs/b5_server_test/verification.json)

目前划分按图片及前景比例分层，已避免完全相同影像跨集合，但缺少来源区域信息，无法证明训练、验证和测试在地理空间上独立，相邻切片可能使内部成绩偏乐观。只有一次固定随机种子训练，未测量多次训练的波动，也未进行官方隐藏测试或Docker断网提交验证。

本次查看测试集后，它已成为公开给实验者的诊断数据；今后的阈值、增强、模型选择应依据训练/验证集。若反复根据这些失败样本改方案，不能继续将同一测试集当作完全未见的最终证据，应另设独立评估或以官方隐藏测试确认泛化。

初步结论：模型已学到有效耕地分割能力，但部分场景存在严重失效。现阶段应称为经过完整训练与内部测试的基线，不能宣称已达到比赛高排名水平。

## 6. 后续实验建议（本次未执行）

优先核查训练/验证集中是否存在与失败样本相同的标注语义或场景问题，并在可能时补充来源区域，采用按区域分组的验证。保留原标签作为依据，不因预测不一致直接改标签。

在验证集上逐项进行对照实验，例如比较正则化与学习率设置、增强策略、边界辅助分支；阈值校准或TTA也只在验证集选择。每次只改变明确因素，记录增益与推理成本。当前结果并未证明这些方法一定有效。

先保留本次best.pt及其完整配置、划分和指标，作为后续比较基准；待方案确定后，再做官方接口、Docker环境和平台评分验证。
